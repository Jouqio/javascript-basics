#  Belajar Array JavaScript (Fokus: Immutable Array)

Modul ini adalah pembelajaran dasar pemrograman JavaScript dengan topik **Array**,
dengan penekanan khusus pada konsep **Immutable Array** menggunakan method
`filter()`, `map()`, dan `reduce()`.

##  Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu diharapkan mampu:
- Memahami apa itu Array dan cara kerjanya di JavaScript
- Membedakan konsep *mutable* vs *immutable* pada Array
- Menguasai method `filter()`, `map()`, dan `reduce()`
- Menggabungkan (chaining) ketiga method tersebut untuk mengolah data
- Menerapkan pola immutable array pada studi kasus nyata

##  Cara Belajar

1. Pelajari materi secara berurutan dari 01 sampai 09 — baca `readme.md` terlebih dahulu.
2. Buka `contoh.js` di tiap folder, lalu jalankan dengan Node.js:
   ```bash
   node "01 Pengantar Array/contoh.js"
   ```
   atau paste ke browser console / [Node.js Playground](https://replit.com/languages/nodejs) untuk melihat hasilnya.
3. Ketik ulang (jangan copy-paste) beberapa contoh kode agar lebih paham.
4. Kerjakan latihan di setiap akhir materi (jawaban latihan juga sudah tersedia di bagian bawah `contoh.js`) sebelum lanjut ke materi berikutnya.
5. Tutup modul dengan mengerjakan Quiz di folder 09.

Selamat belajar!
