Seperti yang telah Anda lihat pada contoh di atas, program mengeksekusi blok kode setelah interval waktu yang ditentukan. Jika Anda ingin menghentikan panggilan fungsi ini, Anda dapat menggunakan clearTimeout()metode tersebut.

Sintaks clearTimeout()metode tersebut adalah:

## clearTimeout(intervalID);

Di sini, adalah intervalIDnilai kembalian dari setTimeout()metode tersebut.
