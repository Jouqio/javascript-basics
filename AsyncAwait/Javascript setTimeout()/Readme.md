Metode ini setTimeout()mengeksekusi blok kode setelah waktu yang ditentukan. Metode ini hanya mengeksekusi kode sekali.

Sintaks yang umum digunakan untuk JavaScript setTimeout adalah:

## setTimeout(function, milliseconds);

Parameter-parameternya adalah:

fungsi - sebuah fungsi yang berisi blok kode
milidetik - waktu setelah fungsi dieksekusi.
Metode ini setTimeout()mengembalikan intervalID , yang merupakan bilangan bulat positif.
