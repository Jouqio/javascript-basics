Async / Await

Tangani operasi yang butuh waktu — tanpa memblokir seluruh program

JavaScript berjalan satu baris per satu baris (single-threaded). Masalah muncul saat ada operasi lambat — fetch API, baca file, akses DB. Dulu solusinya callback, lalu Promise, kini async/await yang paling clean.

Evolusi penanganan async — kode yang sama, tiga era berbeda:

ES5Callback — susah dibaca
ambilUser(id, function(user) { ambilPost(user.id, function(post) { ambilKomentar(post.id, function(komentar) { // 3 level nested — "callback hell"! }); }); });
ES6Promise .then() — lebih baik
ambilUser(id) .then(user => ambilPost(user.id)) .then(post => ambilKomentar(post.id)) .catch(err => tampilError(err));
ES2017async/await — seperti synchronous!
async function main() { try { const user = await ambilUser(id); const post = await ambilPost(user.id); const komentar = await ambilKomentar(post.id); } catch (err) { tampilError(err); } }

Tiga kata kunci penting

asyncTandai fungsi sebagai asynchronous. Fungsi ini akan otomatis mengembalikan Promise.
awaitJeda eksekusi fungsi sampai Promise selesai. Hanya boleh dipakai di dalam fungsi async.
try/catchTangkap error dari await — jika Promise gagal (rejected), eksekusi langsung lompat ke catch.

Tiga pola async/await yang akan kamu pakai di hampir setiap proyek:

1. Fetch data dari API

Pola standar: fetch → cek status → parse JSON → pakai data.

async function ambilPokemon(nama) { const res = await fetch(`https://pokeapi.co/api/v2/pokemon/${nama}`); if (!res.ok) throw new Error(`Gagal: status ${res.status}`); const data = await res.json(); // parse JSON juga async! return { nama: data.name, tinggi: data.height }; } // Panggil fungsinya: async function tampilkan() { try { const pokemon = await ambilPokemon('pikachu'); console.log(`${pokemon.nama}: ${pokemon.tinggi * 10}cm`); } catch (err) { console.error('Error:', err.message); } }

2. Promise.all — fetch paralel

Sequential = tunggu satu-satu (lambat). Paralel = semua jalan bersamaan (cepat).

// Sequential — total waktu = A + B + C const users = await fetch('/users'); // tunggu A selesai const posts = await fetch('/posts'); // lalu B const weather = await fetch('/weather'); // lalu C // Paralel — total waktu = yang paling lambat saja! const [users, posts, weather] = await Promise.all([ fetch('/users'), // A, B, C start bersamaan fetch('/posts'), fetch('/weather') ]); // Catatan: jika SATU dari tiga gagal, semua gagal // Gunakan Promise.allSettled() jika ingin semuanya dicoba

3. Pola error handling yang lengkap

async function kirimForm(data) { try { const res = await fetch('/api/submit', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(data) }); if (!res.ok) { const err = await res.json(); throw new Error(err.message); } return await res.json(); // data sukses } catch (err) { if (err.name === 'TypeError') { // Network error (offline, DNS fail) tampilError('Tidak ada koneksi internet'); } else { tampilError(err.message); // Error dari server } } }

Analogi: async = pesan makanan di restoran

Di restoran, kamu tidak perlu berdiri di dapur sambil menunggu makananmu dimasak. Kamu duduk, ngobrol, pesan minuman — dan makananmu tetap diproses. Itulah cara kerja async.

async function = dapur yang tidak memblokir

Dapur masak pesananmu di background. Restoran tetap bisa layani tamu lain. Begitu pula async function — program tetap jalan sementara operasi lambat berjalan di balik layar.

Promise = struk nomor antrian

Saat memesan, kamu dapat struk (Promise) — bukan makanannya langsung. Struk itu "janji" bahwa makananmu sedang dibuat. Promise bisa fulfilled (makanan jadi) atau rejected (bahan habis).

await = duduk dan tunggu

await adalah instruksi "tunggu di sini sampai pesananmu datang, baru lanjut". Hanya fungsi async yang bisa pakai await — seperti hanya pelanggan restoran yang punya struk yang bisa ambil pesanan.

try/catch = antisipasi pesanan gagal

Kalau menu habis atau dapur error, kamu dapat kabar. try/catch menangkap "kabar buruk" ini — program tidak crash, tapi menangani error dengan elegan.

Untuk latihan ini, kamu butuh environment yang mendukung async — gunakan CodePen, Node.js, atau browser console.

Menantang

Sequential ke Paralel

Ubah kode sequential di bawah menjadi paralel menggunakan Promise.all. Gunakan destructuring untuk ambil hasilnya sekaligus.

// Sequential (lambat) — ubah jadi paralel: const user = await fetch('/api/users/1').then(r => r.json()); const post = await fetch('/api/posts/1').then(r => r.json()); const photo = await fetch('/api/photos/1').then(r => r.json()); // Versi paralel (isi ???): const [user, post, photo] = await Promise.???([???]);
