# Apa itu Dom?

## DOM singkatan dari Document Object Model. 

DOM adalah cara browser "membaca" dan "menyimpan" sebuah halaman HTML menjadi sebuah struktur pohon (tree) yang bisa diakses dan diubah oleh JavaScript.

## Analogi: 

Bayangkan sebuah halaman web adalah sebuah buku resep. DOM adalah daftar isi dari buku tersebut — berisi semua bab, sub-bab, dan isinya. JavaScript bisa membaca daftar isi ini, lalu mengubah judul bab, menambah halaman baru, atau bahkan menghapus resep tertentu!
