ES6+ Modern JavaScript

Arrow function, destructuring, template literal, spread, dan lebih banyak lagi

ES6+ bukan bahasa baru — itu upgrade JavaScript (ES2015 ke atas). Kode yang sama bisa ditulis jauh lebih singkat dan expressif. Lihat perbedaannya:

ES5 (lama)

function sapa(nama) { return 'Halo, ' + nama + '!'; } var users = [{nama:'Budi'}]; var names = users.map(function(u) { return u.nama; });

ES6+ (modern)

const sapa = nama => `Halo, ${nama}!`; const users = [{nama:'Budi'}]; const names = users.map(u => u.nama);

Arrow function — 3 bentuk

// 1. Satu baris — return implicit (tidak perlu return) const kuadrat = n => n * n; // 2. Beberapa parameter const tambah = (a, b) => a + b; // 3. Banyak baris — pakai kurung kurawal + return eksplisit const greet = (nama, usia) => { const sapaan = usia > 17 ? 'Halo' : 'Hai'; return `${sapaan}, ${nama}!`; };

Template literal — string modern

const nama = 'Sari', usia = 23, kota = 'Jakarta'; // ES5 — susah dibaca 'Nama: ' + nama + ', usia ' + usia + ' tahun dari ' + kota; // ES6+ — jauh lebih bersih `Nama: ${nama}, usia ${usia} tahun dari ${kota}`; // Bisa berisi ekspresi JS apapun `${nama} ${usia >= 18 ? 'sudah' : 'belum'} dewasa`; `Total: Rp${(harga * qty).toLocaleString('id-ID')}`;

Destructuring — ambil langsung

// Object destructuring const user = { nama: 'Budi', usia: 25, kota: 'Bandung' }; // ES5 cara lama: const nama = user.nama; const usia = user.usia; // ES6+ — satu baris, langsung dari objek: const { nama, usia, kota } = user; // Dengan default value & rename: const { nama, role = 'Developer', usia: umur } = user; // Array destructuring const warna = ['merah', 'hijau', 'biru']; const [pertama, kedua] = warna; // pertama='merah', kedua='hijau'

Spread & Rest operator

// SPREAD — "tuangkan" isi array/object const arr1 = [1, 2, 3]; const arr2 = [4, 5, 6]; const gabungan = [...arr1, ...arr2]; // [1,2,3,4,5,6] const user = { nama: 'Budi', usia: 25 }; const updated = { ...user, kota: 'Bali' }; // copy + tambah properti baru // REST — kumpulkan sisa argumen const total = (...angka) => angka.reduce((s, n) => s + n, 0); total(1, 2, 3, 4, 5); // → 15

Contoh ES6+ di situasi nyata — kode yang benar-benar kamu tulis di proyek:

Real case 1 — Proses data API

Ambil, filter, dan format data dari API menggunakan chaining + arrow functions.

const users = [ { nama: 'Budi', usia: 17, aktif: true }, { nama: 'Sari', usia: 23, aktif: false }, { nama: 'Dani', usia: 19, aktif: true }, ]; // Filter + map + destructuring dalam satu ekspresi const labelAktif = users .filter(({ aktif }) => aktif) .map(({ nama, usia }) => `${nama} (${usia} thn)`); // → ['Budi (17 thn)', 'Dani (19 thn)']

Real case 2 — Fungsi dengan parameter objek

Destructuring langsung di parameter fungsi + default value.

// Tanpa destructuring (susah dibaca) function buatProfil(options) { const nama = options.nama; const role = options.role || 'Developer'; } // Dengan destructuring + default di parameter langsung const buatProfil = ({ nama, role = 'Developer', skills = [] }) => { const tags = skills.map(s => `<span>${s}</span>`).join(''); return `<h3>${nama}</h3><p>${role}</p>${tags}`; };

Real case 3 — Update state tanpa mutasi (React-style)

Pola immutable yang populer di React & modern JS.

const state = { nama: 'Budi', skor: 10, level: 2 }; // Spread untuk update properti tanpa ubah objek asli const newState = { ...state, skor: state.skor + 5 }; // newState = { nama: 'Budi', skor: 15, level: 2 } // state asli tidak berubah! // Tambah item ke array tanpa mutasi const items = ['a', 'b']; const newItems = [...items, 'c']; // ['a','b','c'] // Hapus item berdasarkan index const tanpaIndex2 = items.filter((_, i) => i !== 2);

Analogi: ES6+ = upgrade smartphone

ES6+ seperti upgrade dari HP jadul ke smartphone. Kamu tetap "menelepon" (menulis JavaScript), tapi caranya jauh lebih mudah, cepat, dan powerful. Fungsinya sama, pengalamannya beda.

Arrow function = touchscreen

Gantikan tombol fisik (function keyword panjang). Fungsinya sama persis, tapi interaksinya jauh lebih smooth dan ringkas. n => n * 2 vs function(n){ return n*2; }

Template literal = autocorrect + emoji keyboard

Dulu nulis string itu repot — sambung satu-satu pakai +. Sekarang tinggal tulis apa adanya dan sisipkan variabel dengan ${...}.

Destructuring = split screen multitasking

Dulu buka satu-satu: const a = x.a; const b = x.b; Sekarang satu langkah ambil semuanya: const {a, b} = x;

Spread = copy-paste cerdas

Salin dan gabungkan array/object dengan mudah: [...a, ...b] atau update tanpa mengubah original: {...user, role: 'Admin'}

Kerjakan di CodePen atau console browser. Fokus pada cara penulisan ES6+, bukan hasilnya saja.
