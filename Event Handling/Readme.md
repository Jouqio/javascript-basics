#  Event Handling — Dasar Pemrograman JavaScript

Modul pembelajaran ini membahas **Event Handling** di JavaScript secara bertahap, dari konsep paling dasar hingga best practice. Materi disusun untuk **pemula**, dengan penjelasan yang jelas dan contoh kode langsung yang bisa dicoba di browser.

##  Daftar Materi

| No | Folder | Topik |

| 01 | `01 Pengantar Event Handling` | Apa itu event & event handling |
| 02 | `02 Cara Menambahkan Event Listener` | 3 cara pasang event, kenapa `addEventListener` terbaik |
| 03 | `03 Event Object` | Informasi detail sebuah event (`target`, `type`, dll) |
| 04 | `04 Event Propagation (Bubbling dan Capturing)` | Fase penyebaran event & `stopPropagation()` |
| 05 | `05 Event Delegation` | Satu listener untuk banyak elemen |

| 07 | `07 Mouse Events` | `click`, `mouseenter`, `mousemove`, dll |
| 08 | `08 Keyboard Events` | `keydown`, `keyup`, `e.key` vs `e.code` |
| 09 | `09 Form Events` | `input`, `change`, `submit`, `focus`, `blur` |
| 10 | `10 Window dan Document Events` | `DOMContentLoaded`, `load`, `scroll`, `resize` |

##  Struktur Setiap Folder

Setiap folder materi berisi:

- **`Readme.md`** → penjelasan konsep lengkap dengan bahasa yang mudah dipahami, disertai tabel, perbandingan, dan potongan kode
- **`contoh.html`** → contoh kode interaktif yang bisa langsung dibuka & dicoba di browser (tinggal klik dua kali file-nya)

##  Cara Belajar

1. Buka folder sesuai urutan nomor (01 → 14)
2. Baca `Readme.md` di setiap folder untuk memahami konsepnya
3. Buka `contoh.html` di browser (klik kanan → *Open with Browser*, atau drag file ke tab browser)
4. Coba ubah-ubah kode di `contoh.html` menggunakan text editor untuk bereksperimen
5. Setelah sampai materi 13, kerjakan **Quiz** di folder 14 untuk menguji pemahaman

##  Target Pembelajaran

Setelah menyelesaikan seluruh modul ini, kamu diharapkan mampu:

- Memahami konsep event dan cara kerja event handling di JavaScript
- Menggunakan `addEventListener()` dengan benar
- Memahami event propagation (bubbling & capturing) dan event delegation
- Menangani berbagai jenis event: mouse, keyboard, form, window
- Membuat dan menggunakan custom event
- Menerapkan best practice agar kode event handling efisien dan mudah dirawat
