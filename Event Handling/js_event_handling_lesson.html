Event Handling

Cara JavaScript "mendengarkan" dan bereaksi terhadap aksi user

Event adalah sesuatu yang terjadi di halaman — klik, ketik, tekan keyboard, submit form. JavaScript bisa "mendengarkan" event dengan addEventListener dan menjalankan kode sebagai respons.

Sintaks addEventListener

// elemen.addEventListener(namaEvent, callbackFunction) const btn = document.querySelector('#tombol'); btn.addEventListener('click', (e) => { // 'e' adalah event object — berisi info tentang event ini console.log(e.target); // elemen yang memicu event console.log(e.type); // 'click' }); // Satu elemen bisa punya BANYAK listener sekaligus: btn.addEventListener('mouseenter', () => btn.style.opacity = '0.7'); btn.addEventListener('mouseleave', () => btn.style.opacity = '1');

Tiga pola event yang paling sering kamu temui di proyek nyata:

1. e.target — tahu elemen mana yang diklik

Berguna saat satu listener menangani banyak elemen (event delegation).

const btn = document.querySelector('#btn'); btn.addEventListener('click', (e) => { // e.target = elemen yang BENAR-BENAR diklik console.log(e.target.id); // 'btn' console.log(e.target.textContent); // teks di tombol e.target.textContent = 'Sudah diklik!'; e.target.disabled = true; }); // Event delegation — 1 listener untuk banyak item list.addEventListener('click', (e) => { if (e.target.tagName === 'LI') { e.target.classList.toggle('done'); } });

2. e.key — deteksi tombol keyboard

document.addEventListener('keydown', (e) => { console.log(e.key); // 'a', 'Enter', 'Escape', 'ArrowUp' console.log(e.ctrlKey); // true jika Ctrl ditekan bersamaan if (e.key === 'Escape') closeModal(); if (e.key === 'Enter') submitForm(); if (e.ctrlKey && e.key === 's') { // Ctrl+S e.preventDefault(); // cegah "Save Page" bawaan browser saveFile(); } });

3. e.preventDefault() — kontrol penuh form

Secara default, form submit = halaman reload. preventDefault() mencegah itu.

form.addEventListener('submit', (e) => { e.preventDefault(); // HENTIKAN reload halaman! const email = document.querySelector('#email').value; if (!email.includes('@')) { errorMsg.textContent = 'Email tidak valid!'; return; } // Lanjut proses tanpa reload console.log('Form berhasil:', email); });

Ringkasan kapan pakai apa:

  • e.target — tahu elemen mana yang memicu event, cocok untuk event delegation
  • e.key — buat keyboard shortcut atau navigasi berbasis keyboard
  • e.preventDefault() — ambil kontrol penuh atas form, link, atau behavior default browser

Analogi: Event = bel rumah

Bayangkan kamu memasang bel di depan rumah. Kamu tidak perlu terus berdiri di pintu — bel akan berbunyi otomatis saat ada tamu, dan kamu langsung bereaksi.

Event = bel yang berbunyi

Ketika user beraksi (klik, ketik, dll), browser "membunyikan bel". Bel ini punya nama: 'click', 'input', 'keydown'.

addEventListener = memasang bel

Dengan addEventListener('click', ...), kamu "memasang bel" di elemen tersebut. Tanpa ini, klik tidak akan terdeteksi.

Callback = aksi yang kamu lakukan

Fungsi yang kamu berikan sebagai argumen kedua — inilah yang otomatis dijalankan setiap kali bel berbunyi.

Event object (e) = amplop dari tamu

Tamu meninggalkan amplop berisi info: siapa yang mengirim (e.target), tombol apa yang ditekan (e.key), posisi kursor, dll.

Kerjakan di CodePen atau console browser (F12). Setiap latihan butuh HTML juga ya!
