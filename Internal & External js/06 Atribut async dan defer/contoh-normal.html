1. Script Normal (Tanpa Atribut)

Tag: <script src="pesan.js"></script>

Browser berhenti baca HTML dulu, download + jalankan pesan.js, baru lanjut baca sisa halaman ini. Buka Console (F12) buat lihat pesannya.

Catatan: karena file ini kecil dan dibuka langsung dari komputer (bukan lewat internet), efek "blocking"-nya gak akan kerasa lambat. Bedanya baru signifikan di website sungguhan dengan banyak/besar file JS.
