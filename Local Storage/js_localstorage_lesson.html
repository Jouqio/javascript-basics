Local Storage

Simpan data di browser — persisten meskipun halaman di-refresh

localStorage adalah tempat penyimpanan key-value di browser yang persisten — data tetap ada meskipun tab ditutup atau halaman di-refresh. Cocok untuk preferensi user, draft, keranjang belanja, dan data ringan lainnya.

Lima metode utama

// Simpan nilai (hanya bisa string!) localStorage.setItem('nama', 'Budi'); // Baca nilai localStorage.getItem('nama'); // → 'Budi' localStorage.getItem('tidakAda'); // → null // Hapus satu key localStorage.removeItem('nama'); // Hapus semua data localStorage.clear(); // Jumlah item tersimpan localStorage.length;

Keterbatasan penting

Hanya string — objek/array harus diubah dulu dengan JSON.stringify()
~5MB per origin — bukan untuk data besar. Untuk lebih besar, gunakan IndexedDB.
Hanya di browser — tidak dikirim ke server (beda dengan cookie). Aman untuk data lokal.

Simpan & baca objek dengan JSON

Karena localStorage hanya bisa simpan string, objek harus di-serialize dulu.

const user = { nama: 'Budi', usia: 25, premium: true }; // Simpan objek → stringify dulu localStorage.setItem('user', JSON.stringify(user)); // Baca objek → parse kembali const saved = JSON.parse(localStorage.getItem('user')); console.log(saved.nama); // 'Budi' // Pola aman — handle jika belum pernah disimpan: const settings = JSON.parse(localStorage.getItem('settings') || '{}'); const cart = JSON.parse(localStorage.getItem('cart') || '[]');

Real case — tema & preferensi user

// Simpan preferensi tema function setTema(tema) { localStorage.setItem('tema', tema); document.body.dataset.tema = tema; // langsung terapkan } // Muat saat halaman dibuka — tema langsung aktif function initTema() { const tema = localStorage.getItem('tema') || 'terang'; // default terang document.body.dataset.tema = tema; } document.addEventListener('DOMContentLoaded', initTema);

Real case — keranjang belanja

function addToCart(produk) { const cart = JSON.parse(localStorage.getItem('cart') || '[]'); const exist = cart.find(p => p.id === produk.id); if (exist) { exist.qty++; // tambah qty jika sudah ada } else { cart.push({ ...produk, qty: 1 }); // spread — ES6! } localStorage.setItem('cart', JSON.stringify(cart)); }

Analogi: localStorage = buku catatan di laci meja

Bayangkan kamu punya tiga cara berbeda untuk menyimpan catatan. Masing-masing punya karakteristik yang berbeda — pilih yang tepat sesuai kebutuhan.

localStorage = buku catatan di laci

Buku catatan yang selalu ada di laci mejamu — tetap ada meskipun kamu pulang, tutup laptop, atau kembali keesokan harinya. Data persisten sampai kamu sendiri yang hapus.

sessionStorage = sticky note di monitor

API-nya persis sama dengan localStorage, tapi data hilang begitu tab ditutup. Cocok untuk data sementara dalam satu sesi seperti progress form multi-step.

JSON.stringify/parse = alat terjemah

Buku catatan hanya bisa menerima tulisan (string). Kalau kamu mau simpan objek, kamu butuh "penerjemah" — stringify saat simpan, parse saat baca kembali.

Kerjakan di console browser (F12). Coba refresh halaman setelah simpan — apakah data masih ada?
