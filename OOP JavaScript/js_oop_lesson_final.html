OOP JavaScript

Class, constructor, method, inheritance — kode terstruktur seperti developer profesional

OOP (Object-Oriented Programming) adalah cara mengorganisir kode menjadi class — template yang mendeskripsikan data dan aksi suatu entitas. Daripada data dan fungsi berserakan, semuanya terkumpul rapi dalam satu class.

Tanpa OOP — berserakan

const u1 = { nama:'Budi', usia:25 }; const u2 = { nama:'Sari', usia:23 }; function sapa(u) { return `Halo ${u.nama}`; } function dewasa(u) { return u.usia >= 18; }

Dengan class — terstruktur

class User { constructor(nama, usia) { this.nama = nama; this.usia = usia; } sapa() { return `Halo ${this.nama}`; } get dewasa() { return this.usia >= 18; } } const u = new User('Budi', 25);

Anatomi class — semua bagian penting

class Produk { // nama class selalu PascalCase #harga; // private field — tidak bisa diakses dari luar! constructor(nama, harga) { // dipanggil saat new Produk(...) this.nama = nama; this.#harga = harga; } tampil() { // instance method return `${this.nama}: Rp${this.#harga}`; } get hargaDiskon() { // getter — diakses sebagai properti (tanpa ()) return this.#harga * 0.9; } set harga(val) { // setter — validasi saat assignment if (val < 0) throw new Error('Harga tidak boleh negatif'); this.#harga = val; } static buat(nama, harga) { // static — dipanggil dari class, bukan instance return new Produk(nama, harga); } } const mie = new Produk('Indomie', 3500); mie.tampil(); // 'Indomie: Rp3500' mie.hargaDiskon; // 3150 — akses getter tanpa () mie.harga = 4000; // setter dipanggil otomatis Produk.buat('Kopi', 5000); // static method

Inheritance — extends & super

Class bisa mewarisi semua properti dan method dari class lain, lalu menambahkan fitur baru.

class Animal { constructor(nama, suara) { this.nama = nama; this.suara = suara; } bicara() { return `${this.nama}: ${this.suara}`; } } class Dog extends Animal { // Dog mewarisi semua dari Animal constructor(nama) { super(nama, 'Guk!'); // WAJIB panggil super() sebelum this this.trik = []; } belajar(trik) { this.trik.push(trik); } tampilTrik() { return `${this.nama} bisa: ${this.trik.join(', ')}`; } } const rex = new Dog('Rex'); rex.bicara(); // 'Rex: Guk!' — method dari Animal rex.belajar('duduk'); rex.tampilTrik(); // 'Rex bisa: duduk' — method dari Dog

Contoh nyata — hierarki User & Admin

class User { constructor(nama, email) { this.nama = nama; this.email = email; this.role = 'user'; } sapa() { return `Halo, ${this.nama}!`; } } class Admin extends User { constructor(nama, email, level) { super(nama, email); // ambil semua dari User this.role = 'admin'; // override properti parent this.level = level; } hapusUser(id) { /* hanya admin bisa */ } sapa() { // override method parent return `[Admin Lv.${this.level}] ${super.sapa()}`; } } const admin = new Admin('Budi', 'budi@dev.id', 3); admin.sapa(); // '[Admin Lv.3] Halo, Budi!'

Analogi: class = blueprint rumah

OOP bukan sekadar cara menulis kode — ini adalah cara berpikir tentang masalah. Bayangkan kamu seorang arsitek yang membuat blueprint sebelum membangun.

Class = blueprint/cetakan

Blueprint rumah bukan rumah itu sendiri — ia hanya mendeskripsikan seperti apa rumah yang akan dibangun. Class mendefinisikan properti apa yang dimiliki dan aksi apa yang bisa dilakukan.

Instance = rumah yang sudah jadi

new User('Budi', 25) = membangun satu rumah dari blueprint. Kamu bisa bangun ribuan rumah dari blueprint yang sama — setiap rumah independen, tidak saling memengaruhi.

Inheritance = renovasi upgrade

class Admin extends User = ambil blueprint User yang sudah ada, tambahkan lantai baru (fitur baru), tanpa mengubah blueprint User asli. Reuse kode, kurangi duplikasi.

Private field (#) = ruangan terkunci

Ruangan yang hanya bisa diakses dari dalam rumah — tamu tidak bisa masuk langsung. #password tidak bisa diakses dari luar class, hanya melalui method yang disediakan.

Kerjakan di console browser atau CodePen. Uji setiap class dengan membuat beberapa instance dan memanggil methodnya.
